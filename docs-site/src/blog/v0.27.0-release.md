# Release: mxcli v0.27.0

*October 15, 2026*

v0.27.0 makes **`exec` all or nothing**. If a statement fails at write time, the whole run is rolled back, so a script never leaves a project half-changed. Around that sits a large wave of round-trip fixes: describing real apps, checking the output and executing it again now works far more often.

## What's new

**All-or-nothing `exec`.** Before, a statement that failed at write time left every statement before it in place: a created module stayed, and a `drop` ahead of the failing `create` was not undone. Now mxcli backs up the `.mpr` and every unit file a run touches before the first write, and restores them if anything fails. The message reads "Nothing was written: statement N was rolled back".

**Round trips over real apps.** We ran `describe` → `check` → `exec` over complete applications: the Siemens FSM template, the GenAI showcase and Marketplace modules. Every place where the description didn't check, or didn't execute back to the same model, is now fixed. That covers indexes on system date members, layouts built on other layouts, Mendix 9 pluggable data sources, decisions on enumeration rules, doc comments with bullets, mutually recursive microflows, and more. `describe module --all` now emits every document type.

**Mendix 9 projects.** Microflows, nanoflows and pages with pluggable widgets can be written to 9.x projects again. `run --local` picks JDK 17 for them.

**`check -p` catches more before `exec` does.** It now checks access rule XPaths, event handler microflows, enumeration keys, view entity sources, DataGrid 2 column attributes, ALTER PAGE targets, and references to image collections and flows the same script creates.

**New in MDL.** The classic `filemanager` widget, role-based visibility with `Visible: roles (Mod.A, …)`, and `+=` / `-=` for reference sets inside `change`. ALTER PAGE can now address navigation list items (`nav item('Home')`) and widgets inside Accordion groups.

**The domain model, drawn.** `mxcli describe --format svg domainmodel <Module>` draws a module's domain model as SVG, with entities where Studio Pro shows them and boxes sized to fit every name. The Claude Code companion shows the diagram when you select a Domain Model node, with pan, fit and a full-width view.

**Security.** The MongoDB BSON driver is upgraded for the October 2026 advisories, which release scanners flagged on the published binaries.

## Upgrading

Download the `v0.27.0` binary for your platform from the [release page](https://github.com/mendixlabs/mxcli/releases/tag/v0.27.0):

```bash
curl -fsSL -o mxcli \
  https://github.com/mendixlabs/mxcli/releases/download/v0.27.0/mxcli-linux-amd64
chmod +x mxcli && sudo mv mxcli /usr/local/bin/
```

Then refresh a project's skills, commands and the companion mod with `mxcli init --sync-skills`.

**One breaking change:** mxcli no longer creates a module role on its own. A new page, microflow or nanoflow in a module with no roles used to create `<Module>.User` and grant itself to it. Now a new document starts with no allowed roles. If a script grants to `<Module>.User`, add `create module role <Module>.User;` before the grant.
