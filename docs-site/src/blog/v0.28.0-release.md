# Release: mxcli v0.28.0

*October 23, 2026*

v0.28.0 is about **changing one thing without restating the rest**. You can now edit a menu item, a REST operation or a single widget in place, and a flow can take a reworded note or decision caption without being rebuilt.

## What's new

**Edit menus in place.** Adding one menu item used to mean restating the whole menu. Now:

```sql
alter navigation Responsive {
  set (Caption: 'People') on 'Admin' > 'Users';
  drop 'Old';
};
```

Items are addressed by their caption path, and mxcli never guesses. An address that matches nothing or several items is refused, and the message lists the candidates. `alter menu` does the same for menu documents. `alter consumed rest service` adds, changes and removes operations without restating the service.

**ALTER PAGE reaches every widget.** You can now address legacy table cells by position (`table1 cell(1,2)`), Accordion groups and other pluggable widget items (`acc1 item@2`, `acc1 item@1.headercontent`), and named slots such as `dataGrid1.controlbar`. Rewriting a page, snippet or layout also no longer deletes the widgets MDL can't author.

**Flows change in place.** Under `mdl 1`, `create or modify` now splices a reworded note, a changed decision caption, or a change to an activity with a custom error handler, where it used to refuse them as a rebuild.

**Protected add-on modules.** `check -p --references` now catches the Hidden-element references that mxbuild refuses (CE1406, CE5400). Entities, attributes, associations and enumerations take `export level api|hidden`.

**Marketplace modules out.** `mxcli marketplace package MyModule` exports a module as a `.mpk`. `marketplace install` now runs the widget and design-property repairs itself.

**The local dev loop.** `run --local` passes your configuration's JVM options and starts with scheduled events running. `--listen-addr` makes the app reachable from another device, and `--db-admin-user` handles password-protected PostgreSQL. `--watch` also recovers from two `mxbuild --serve` faults that left pages returning 404 or a fixed theme still failing.

**Security.** The deprecated v1 BSON driver is gone, so mxcli now runs on `mongo-driver/v2` alone, and a test stops it from coming back. Go moves to 1.27.3, and the npm advisories in the bundled widget and the VS Code extension are cleared.

## Upgrading

Download the `v0.28.0` binary for your platform from the [release page](https://github.com/mendixlabs/mxcli/releases/tag/v0.28.0):

```bash
curl -fsSL -o mxcli \
  https://github.com/mendixlabs/mxcli/releases/download/v0.28.0/mxcli-linux-amd64
chmod +x mxcli && sudo mv mxcli /usr/local/bin/
```

Then refresh a project's skills, commands and the companion mod with `mxcli init --sync-skills`. It now keeps a bundled lint rule you edited, and doesn't recreate one you renamed.

Behaviour changes worth knowing:

- `check -p` now applies the same Mendix version gates as `exec`, so a statement your project's version can't store fails at check time instead of halfway through `exec`.
- `run --local` now runs scheduled events. Pass `--runtime-setting ScheduledEventExecution=NONE` to keep them off.
